# Упутство за инсталацију

Уређаји: **Samsung Galaxy Tab A11 (8,7", 64 GB)** и рачунар са **Windows 11**.
Према спецификацијама произвођача, Tab A11 долази са Android 15 / One UI 7 и Chrome-ом. То је довољно за PWA. Тачну ознаку модела (SM-X13x) и верзију Android-а провјерите у *Подешавања → О таблету → Информације о софтверу*. Уз Android 10 или новији и ажуран Chrome упутство важи без измјена.

## Шта је PWA, а шта APK

| | **PWA (препоручено)** | **APK датотека** |
|---|---|---|
| Како се инсталира | Отворите адресу у Chrome-у → „Додај на почетни екран / Инсталирај апликацију“ | Преузмете `.apk` и дозволите „инсталирање из непознатих извора“ |
| Шта је потребно | Да апликација буде једном доступна преко HTTPS адресе (или `localhost`) | Израда у Android Studio-у (Capacitor) или преко PWABuilder-а уз HTTPS адресу |
| Икона, цијели екран, рад без интернета | Да | Да |
| Ажурирање | Аутоматски се нуди нова верзија (ви потврђујете) | Ручно инсталирате нови APK |
| Исти код на рачунару | Да (Chrome/Edge → „Инсталирај“) | Не, APK је само за Android |
| Гдје су подаци | У складишту прегледача за ту адресу | У складишту апликације |

За овај уређај APK није потребан, јер Chrome на Android-у у потпуности подржава PWA.
APK има смисла ако желите инсталацију потпуно без прегледача или дистрибуцију ван интернета. Тада се исти `dist/` пакује помоћу [Capacitor](https://capacitorjs.com)-а у Android Studio-у. То није дио прве верзије.

> **Важно:** подаци се везују за **адресу** са које је апликација инсталирана. Ако касније промијените адресу (други хостинг), то је нова, празна инсталација. Податке тада пренесите JSON резервном копијом.

## Корак 1: поставите апликацију на адресу коју таблет може да отвори

Service worker (рад без интернета) ради само преко **HTTPS** или на адреси **localhost**. Обична адреса у локалној мрежи (нпр. `http://192.168.1.5:4173`) отвара апликацију, али **не** омогућава рад без интернета. Зато изаберите једну од двије опције.

### Опција А: GitHub Pages (подешено)

Апликација је објављена на **https://flopicic597-boop.github.io/trener/**. На таблету и рачунару отворите ту адресу у Chrome-у и наставите Кораком 2.
Нову верзију објављујете двоструким кликом на **`OBJAVI.cmd`**. Скрипта покреће тестове, прави апликацију и шаље је на грану `gh-pages`. Послије 1–2 минута апликација на уређајима нуди „Ажурирај“.

Општи поступак за било који статички хостинг:

На хостинг се поставља само код апликације (фасцикла `dist/`). **Подаци клијената остају на таблету** и никад се не шаљу на хостинг.

1. На рачунару, у фасцикли `gotovo`, покрените `npm install` и `npm run build`.
2. Садржај фасцикле `dist/` поставите на бесплатан статички хостинг са HTTPS-ом, нпр. **GitHub Pages**, **Cloudflare Pages** или **Netlify**. Апликација користи релативне путање, па ради и у подфасцикли (нпр. `https://korisnik.github.io/trener/`).
3. Добијену `https://…` адресу отворите на таблету (Корак 2).

### Опција Б: потпуно локално, преко USB кабла (без хостинга)

**Брзи начин:** двоструки клик на **`TABLET.cmd`** у фасцикли `gotovo`. Скрипта прави апликацију, чека таблет, повезује га (`adb reverse`) и покреће сервер. Затим на таблету отворите **http://localhost:4173** (Корак 2). Прозор скрипте држите отворен док траје инсталација.

Припрема (једном):
- **Опције за програмере на таблету:** *Подешавања → О таблету → Информације о софтверу* → 7 пута додирните **Број израде**. Затим *Подешавања → Опције за програмере* → укључите **USB отклањање грешака**.
- При првом прикључивању таблет пита „Дозволити USB отклањање грешака?“. Означите *Увијек дозволи са овог рачунара* и потврдите са **Дозволи**.
- `adb` је на овом рачунару већ инсталиран (`winget install Google.PlatformTools`).

Када је апликација инсталирана, USB отклањање грешака можете искључити. Апликација ради без кабла и без интернета. Кабл и `TABLET.cmd` поново су потребни само за надоградњу.

Ручно, корак по корак:

1. На таблету укључите *Опције за програмере → USB отклањање грешака*.
2. На рачунар инсталирајте [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (`adb`).
3. На рачунару, у фасцикли `gotovo`, покрените:

```bash
npm run build
```

```bash
npm run preview
```

4. Повежите таблет кабловски и у другом прозору покрените:

```bash
adb reverse tcp:4173 tcp:4173
```

5. На таблету у Chrome-у отворите **http://localhost:4173** и наставите Кораком 2.

Ограничење: за сваку будућу надоградњу поново покрећете `TABLET.cmd` (или кораке 3–5). Користите увијек исту адресу, **http://localhost:4173**. Друга адреса или порт значи нову, празну базу.

## Корак 2: инсталација на таблету (Chrome)

1. Отворите адресу у **Chrome-у** (не у Samsung Internet-у, ако желите исто понашање као у упутству).
2. Сачекајте поруку **„Апликација је спремна за рад без интернета“**.
3. Мени **⋮ → Додај на почетни екран → Инсталирај** (или „Инсталирај апликацију“).
4. Апликацију убудуће покрећите са иконе **Тренер**. Отвара се преко цијелог екрана.
5. Провјера: укључите режим рада у авиону, затворите и поново отворите апликацију. Мора се отворити са подацима.
6. У апликацији: **Подаци и копије → 5. Простор за чување**. Ако пише „није одобрено“, додирните **Затражи трајно чување**. Chrome га најчешће одобрава када је апликација инсталирана.

## Корак 3: рачунар (Windows 11)

- **Иста адреса као таблет (опција А):** отворите је у Chrome-у или Edge-у и кликните икону **Инсталирај** у адресној траци.
- **Локално:** у фасцикли `gotovo` покрените `npm run preview`, отворите **http://localhost:4173** и инсталирајте на исти начин.

Таблет и рачунар имају **засебне** базе. Подаци се преносе JSON датотеком, као што је описано у [упутству за пренос](PRENOS-I-REZERVNE-KOPIJE.md).

## Прво покретање

1. **Подаци и копије → 6. Пробни подаци → Учитај** ако желите да видите апликацију са примјерима. Уклањају се једним дугметом без утицаја на стварне податке.
2. **Клијенти → + Нови клијент**.
3. **Програми → + Нови програм**, додајте вјежбе и планиране серије.
4. На профилу клијента изаберите дан у календару → **+ Нови тренинг** → изаберите програм.
5. Током тренинга: расположење (1–5), сан, за сваку серију понављања/трајање и кг, па **✓** када је серија готова. Све се чува аутоматски, а статус чувања је доле десно.

## Ажурирање апликације

Када поставите нову верзију (`npm run build` и поновно постављање `dist/`), апликација приказује **„Доступна је нова верзија“**. Ништа се не освјежава само од себе. Додирните **Ажурирај сада** када завршите унос. Ако постоји несачуван унос, ажурирање се одлаже. Подаци у бази остају, а промјене шеме обављају миграције.
