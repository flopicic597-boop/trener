# Аутоматски пренос таблет ↔ рачунар (Supabase)

Подаци се **шифрују на уређају** вашом лозинком за шифровање (AES-256) и тек онда шаљу у ваш Supabase пројекат. Сервер чува само нечитљив садржај: клијенти, тренинзи, налази и прилози се не могу прочитати ни у Supabase конзоли. Видљива су само техничка поља (врста записа, идентификатор, вријеме измјене).

## 1. Пројекат (једном, око 5 минута)

1. <https://supabase.com/dashboard> → **New project**. Назив: `trener`, регион **Central EU (Frankfurt)**. Лозинку базе сачувајте код себе (апликацији није потребна).
2. **SQL Editor → New query** → налијепите цијели садржај датотеке [`supabase/setup.sql`](../supabase/setup.sql) → **Run**. Треба да пише *Success*.
3. **Authentication → Sign In / Providers → Email** → искључите **Allow new users to sign up** (нико други не може направити налог).
4. **Authentication → Users → Add user → Create new user**: ваша е-пошта и лозинка налога, укључите **Auto Confirm User**.
5. **Project Settings → API Keys**: копирајте **Project URL** (`https://….supabase.co`) и **Publishable key** (`sb_publishable_…`). Ово су ЈАВНЕ вриједности. **Никад** не користите `service_role` / `secret` кључ.

## 2. Апликација

Адреса и јавни кључ се уграђују у апликацију (датотека `.env.local`, не шаље се на GitHub):

```
VITE_SUPABASE_URL=https://….supabase.co
VITE_SUPABASE_KEY=sb_publishable_…
```

затим `OBJAVI.cmd`. (Без тога се исте вриједности могу унијети ручно у апликацији.)

## 3. Уређаји

**Први уређај (таблет, јер на њему су подаци):** *Подаци и копије → Аутоматски пренос* → пријава (е-пошта и лозинка налога) → **поставите лозинку за шифровање** (бар 10 знакова, другачија од лозинке налога). **Запишите је** — без ње се копија на серверу не може дешифровати.

**Други уређај (рачунар):** иста пријава → унесите исту лозинку за шифровање. Подаци са таблета стижу за неколико секунди.

> Прије укључивања на уређају на коме сте учитали **пробне податке**, уклоните их (*Подаци и копије → Пробни подаци*). Пробни подаци се ионако не шаљу.

## Како ради

- Пренос се покреће сам: при отварању апликације, сваки минут док је отворена, неколико секунди послије уноса, при повратку интернета и при изласку из апликације. Ознака **☁ ЧЧ:ММ** доле лијево показује посљедњи пренос (додир води на подешавања).
- Без интернета све се чува локално и шаље чим се веза врати.
- Ако је исти запис мијењан на оба уређаја, задржава се **новија измјена** (по времену измјене). Брисање се преноси.
- Приложени PDF-ови и слике иду шифровано у приватну фасциклу налога (Storage).

## Важно

- **Бесплатни Supabase пројекат се паузира послије 7 дана без коришћења.** Тада ознака пише „пренос: грешка“. Отворите Supabase dashboard → пројекат → **Restore/Resume**. Подаци се не губе, а на уређајима увијек остају.
- Бесплатни план нема резервне копије које се могу преузети. **JSON резервна копија у апликацији остаје препорука** (нпр. једном седмично на рачунару).
- Лозинку налога можете промијенити у Supabase-у; лозинку за шифровање не (нова лозинка = нови пројекат/нов почетак преноса).
- Одјава са уређаја (*Подаци и копије → Аутоматски пренос → Одјава*) не брише податке са уређаја.
