# Провјерене функције и преостала ограничења

Стање на дан 12.11.2026. Провјера је рађена у Chromium прегледачу на Windows 11 (уграђени прегледач развојног окружења), на величинама екрана 800×1280 (таблет усправно), 1280×800 (таблет положено) и 1366×768 (рачунар), уз аутоматске тестове.
**На самом Galaxy Tab A11 апликација није тестирана.** То провјерите ви, по списку на дну.

## Аутоматски тестови (`npm test`, 25 тестова, сви пролазе)

- Обрачун обима: само завршене серије са спољним оптерећењем, без плана, незавршених, обрисаних, вјежби на вријеме и са сопственом тежином; недостајућа вриједност није нула; децимална тежина.
- Унос бројева: зарез и тачка, празно = нема вриједности, неисправан унос се одбија; трајање (`1:30`, `45`, `1,5м`); темпо (`3–1–1–0`, `3110`, `2-0-X-0`).
- Валидација: расположење 1–5, сан 0–24, ненегативни бројеви.
- Периоди: претходни период исте дужине, седмични/мјесечни бројеви завршених тренинга, серије без недостајућих вриједности.
- Напредак: пореди само исти број понављања / исту тежину; већи збир кг без упоредивих серија не даје закључак.
- Основни ток у бази: клијент → програм → тренинг из програма → унос → копирање претходне серије; измјена шаблона не мијења сачуван тренинг; више тренинга истог дана; претходни резултат исте вјежбе; архивирање чува историју; редослијед вјежби; уклањање пробних података.
- Извоз/увоз: пренос на другу инсталацију; поновни увоз без дупликата; измјена само на једном уређају се преузима; измјена на оба = сукоб без тихог преписивања; избор локалне верзије; неисправне датотеке; миграција старог формата датотеке; неуспјели увоз оставља базу непромијењеном; снимак и враћање; CSV са BOM-ом и ћирилицом.
- Миграција базе v1 → v2 без губитка података.

## Шта треба да провјерите на таблету

1. Инсталација из Chrome-а и отварање са иконе (Android 15 / One UI 7 према спецификацији; провјерите своју верзију).
2. Режим рада у авиону: апликација се отвара и чува унос.
3. **Подаци и копије → 5.**: да ли је „трајно чување“ одобрено послије инсталације.
4. „Сачувај резервну копију“: датотека се појављује у *Moje datoteke → Преузимања*.
5. „Подијели датотеку…“: да ли се отвара Android дијељење (Quick Share / Gmail / Drive).
6. Избор JSON датотеке при увозу на таблету.
7. Величина дугмади и текста при уносу прстом током тренинга (усправно и положено).
8. Бирач датума приказује формат по подешавањима уређаја (у тест-прегледачу је био амерички ММ/ДД/ГГГГ).
9. Брзина са већом количином података (нпр. послије неколико мјесеци рада).
10. Отварање CSV датотеке у вашој верзији Excel-а.

## Ограничења прве верзије

- **Нема аутоматске синхронизације.** Пренос је ручни, JSON датотеком.
- Подаци су у складишту прегледача. Брисање података сајта/апликације их уклања, па редовно правите резервне копије.
- Апликација мора бити једном учитана преко HTTPS-а или `localhost`-а (види упутство за инсталацију). Обична адреса у локалној мрежи не омогућава рад без интернета.
- Таблет и рачунар имају засебне базе. Свака инсталација са друге адресе је нова, празна база.
- Нема PIN-а ни шифровања базе. Заштиту пружа закључавање таблета (PIN/отисак). PIN у апликацији не би био шифровање, па није додат.
- Сукоб се рјешава по цијелом запису (бира се једна верзија), не по појединачном пољу.
- Брисање вјежбе из библиотеке није могуће, само архивирање, да се не изгуби историја.
- Тренинг се може трајно обрисати уз потврду. За неодржан тренинг препоручује се статус „Прескочен“.
- Графикони су једноставни SVG графикони без зумирања; вриједности се виде у табеларном приказу или додиром тачке (наслов тачке).
- Седмични графикон може имати непотпуну прву седмицу ако период не почиње понедјељком.
- `npm install` пријављује 6 упозорења о рањивостима у развојним алатима (не улазе у апликацију на таблету).
