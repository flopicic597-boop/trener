# Тренер – евиденција клијената (PWA)

Апликација за једног тренера: клијенти, дневни унос тренинга (расположење, сан, серије), програми и шаблони, преглед по данима, графикони напретка, **чланарине** (уплате и истек), **налази и анализе** (PDF/слике, вриједности, поређење и напомене за рад), JSON резервне копије и CSV за Excel.
Ради **без интернета** након првог учитавања и чува податке **локално** на уређају (IndexedDB у прегледачу). Нема сервера, налога ни аналитике. Подаци клијената се не шаљу никуда.

Интерфејс је на српском језику, ћирилицом (ијекавица). Изглед и библиотека вјежби су по узору на `../uzor/Trening platforma (1).html`: све вјежбе из узора су пренесене у ћирилицу, уз проширење на 152 вјежбе у 8 категорија.

## Брзи почетак (Windows 11)

Потребан је [Node.js](https://nodejs.org) 20 или новији (провјерено са 26.13).

```bash
npm install
```

```bash
npm test
```

```bash
npm run build
```

```bash
npm run preview
```

Затим отворите **http://localhost:4173** у Chrome-у или Edge-у. За развој са аутоматским освјежавањем користите `npm run dev` (service worker тада није активан, па рад без интернета провјеравајте преко `build` + `preview`).

| Команда | Шта ради |
|---|---|
| `npm run dev` | развојни сервер (http://localhost:5173) |
| `npm run build` | производна верзија у фасцикли `dist/` |
| `npm run preview` | служи `dist/` на http://localhost:4173 |
| `npm test` | аутоматски тестови (Vitest) |
| `npm run icons` | поново прави иконе у `public/` |

Фасцикла `dist/` је комплетна апликација (око 2 MB, од чега је 1,7 MB читач PDF налаза) и може се поставити на било који статички HTTPS хостинг. Нову верзију на GitHub Pages објављујете са `OBJAVI.cmd`.

## Технологије

| Дио | Избор | Зашто |
|---|---|---|
| Интерфејс | чист JavaScript (ES модули), без оквира | мало, брзо на слабијем хардверу |
| База | IndexedDB преко [Dexie 4.4](https://dexie.org) | верзионисана шема и миграције |
| Рад без интернета | [vite-plugin-pwa 2.0](https://vite-pwa-org.netlify.app) (Workbox) | кеширање, контролисано ажурирање |
| Израда | Vite 8 | брза израда, мала датотека |
| Графикони | сопствени SVG | без спољних библиотека |
| Читање PDF налаза | [pdf.js 6.4](https://mozilla.github.io/pdf.js/) | ради на уређају, датотека се не шаље никуд |
| Тестови | Vitest 5 + fake-indexeddb | тестови базе у Node-у |
| Фонт | Roboto Condensed (ћирилица, уграђен) | исти изглед без интернета |
